# Offset Pad

<p align="center"><img src="media/OffsetPad.png" alt="Offset Pad Logo" width="180"></p>

Offset Pad 给没有独立数字小键盘的小配列键盘增加一个数字键层，支持 Windows x64。

## 为什么做这个

小配列键盘通常没有独立数字小键盘。虽然日常打字很少用到它，但在处理表格或集中录入数字时，九宫格布局又很顺手。

Offset Pad 把右手打字区临时变成近似九宫格的小键盘。左手按快捷键切换，右手保持原来的打字位置，就能按熟悉的布局输入数字；用完再切回普通键盘，无需移动手腕或另外接一个小键盘。

## 快速开始

1. 运行 Windows x64 安装包，安装并打开 Offset Pad。
2. 点击状态卡片上的 `OFF` / `ON`，或按默认快捷键 **`LCtrl` + `Caps Lock`** 切换模式；按住 **`Caps Lock` + `Shift`** 并输入字符可临时使用小键盘，松开后恢复。
    - 由于我电脑后台有很多效率工具，顺手的快捷键基本都已经被其他软件占用了，所以专门去适配了 **`Caps Lock`** 键来作为快捷键，将「`Caps Lock` + 功能键」作为快捷键不会被`Caps Lock`原有的功能干扰，短按 `Caps Lock` 仍保留原有的大小写锁定功能；按住 `Caps Lock` + `Shift` 输入数字，松手后恢复原模式。
3. 点击“按键映射”中左侧的键帽，按字母、数字、常用符号、空格或左右 Ctrl/Alt/Shift/Win 重新绑定；按 **`Esc`** 取消。已占用的键会与原键交换。映射侧只在小键盘模式下作为输入，另一侧仍可正常组成快捷键。
4. 设置窗口可分别设置“切换模式”和“按住输入”：按住后暂时输入数字，松开即恢复此前模式；按住输入期间按 Backspace 只删除一个字符。录入时会区分**左右 `Ctrl`、`Alt`、`Shift`** 和 **`Win`**，并显示为 **`LCtrl`**、**`RCtrl`** 等；按 **`Delete`** 或 **`Backspace`** 可清除录入中的快捷键；托盘菜单可禁用两种快捷键，单独的模式开关仍可使用。快捷键需由 2–4 个按键组成，不支持单键触发。
5. 小键盘模式下，顶部数字行会映射为对应符号，不需按`shift`；

默认映射如下：

| 原键 | 输出 |
| --- | --- |
| `U` `I` `O` | `7` `8` `9` |
| `J` `K` `L` | `4` `5` `6` |
| `N` `M` `,` | `1` `2` `3` |
| 空格 | `0` |
| `.` ( 即 `>` 键 ) | `.` |


“屏蔽未映射字符”默认开启，开启时其他未映射的字符键会被拦截，方向键、回车和删除等功能键保持可用。

关闭设置窗口后，程序仍在系统托盘运行。托盘图标为 `O` 时是普通键盘模式，为 `9` 时是数字小键盘模式；映射直接输入数字字符，不受 Num Lock 状态影响。
