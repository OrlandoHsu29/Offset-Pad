# Offset Pad

<p align="center"><img src="media/OffsetPad.png" alt="Offset Pad Logo" width="180"></p>

Offset Pad 给没有独立数字小键盘的小配列键盘增加一个数字键层，支持 Windows x64。

## 为什么做这个

小配列键盘通常没有独立数字小键盘。虽然日常打字很少用到它，但在处理表格或集中录入数字时，九宫格布局又很顺手。

Offset Pad 把右手打字区临时变成近似九宫格的小键盘。左手按快捷键切换，右手保持原来的打字位置，就能按熟悉的布局输入数字；用完再切回普通键盘，无需移动手腕或另外接一个小键盘。

## 快速开始

 在 **`releases`** 下载最新发布的 Windows x64 安装包并运行，安装并打开 `Offset Pad`。（目前仅支持 Windows ）

![Offset Pad 设置窗口](media/run.png)

## 使用说明
1. 点击状态卡片上的 `OFF` / `ON`，或按默认快捷键 **`LCtrl` + `Caps Lock`** 切换模式；按住 **`Caps Lock` + 左 `Shift`** 并输入字符可临时切换为`小键盘模式`，松开后恢复`普通键盘模式`。
    - 由于我自己电脑后台有很多效率工具，能单独左手触发且方便的快捷键基本都已经被占用了，所以专门去适配了 **`Caps Lock`** 键来作为修饰键，将「`Caps Lock` + 功能键」作为快捷键不会被 `Caps Lock` 原有的功能干扰，单独按 `Caps Lock` 仍保留原有的大小写锁定功能。
2. 支持修改「数字映射键」和「小键盘模式开关快捷键」，录入快捷键时会区分**左右修饰键 `Ctrl`、`Alt`、`Shift`** 和 **`Win`**，并显示为 **`LCtrl`**、**`RCtrl`** 等；按 **`Delete`** 或 **`Backspace`** 可清除录入中的快捷键；托盘菜单中可禁用快捷键。快捷键需由 2–4 个按键组成，不支持单键触发。
3. 小键盘模式下，顶部数字行会映射为对应符号，不需按`shift`；
4. 「屏蔽未映射字符」默认开启，开启时其他未映射的字符键会被拦截，方向键、回车和删除等功能键保持可用；
5. 「按住输入」时会屏蔽其他快捷键，「切换模式」时其他快捷键则可以正常使用；
6. 关闭设置窗口后，程序仍在系统托盘运行。托盘图标为 `O` 时是普通键盘模式，为 `9` 时是数字小键盘模式，以提示当前状态；

    | 普通键盘模式 | 数字小键盘模式 |
    | :---: | :---: |
    | <img src="media/OffsetPad-icon-o.png" alt="普通键盘模式托盘图标 O" width="64"> | <img src="media/OffsetPad-icon-9.png" alt="数字小键盘模式托盘图标 9" width="64"> |

7. 按键实际将映射为顶部数字行的数字键，因此不受 Num Lock 状态影响，同时也能被一些键盘回显程序识别。

默认数字映射如下：

| 原键 | 输出 |
| --- | --- |
| `U` `I` `O` | `7` `8` `9` |
| `J` `K` `L` | `4` `5` `6` |
| `N` `M` `<` | `1` `2` `3` |
| `空格` `>` | `0` `.`|

符合标准打字指法的右手放置位置，因此无需移动手腕。习惯后在输入数字效率上可能会略高于使用实际小键盘输入数字。

## 已知局限

在「按住输入」期间，少数键盘在多个映射按键（2个以上）同时按下或快速交错按下时，可能受键盘矩阵或固件的多键识别能力限制（大体上是 **无全键无冲能力** 所导致的问题，但还不能确定是否所有这些情况都由此造成），导致重复输出同一数字或直接退出小键盘模式。修改快捷键可能能一定程度上缓解这种问题，但也会导致输入出现轻微的延迟或卡顿。
